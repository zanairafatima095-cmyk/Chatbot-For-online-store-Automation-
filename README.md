# Nova Store Chatbot

An AI-powered customer support automation system for an online store, built with **n8n**, **Gemini AI**, **Telegram**, and **Google Sheets**.

 🎯 Overview
Nova Store Chatbot is a 5-workflow AI customer support agent that handles order lookups, complaints, ticket management, admin notifications, and daily support analytics — all through Telegram.

⚙️ Tech Stack
- **n8n** – Workflow automation and orchestration
- **Google Gemini AI** – Natural language understanding for customer queries
- **Telegram** – Customer-facing chat interface
- **Google Sheets** – Backend database for orders, tickets, and analytics

 🔄 Workflows
1. **Order Lookup System** – Customers check order status via Telegram
2. **Complaint and Ticket Management** – Logs and tracks customer complaints as support tickets
3. **Admin Notification System** – Alerts admins of new tickets or urgent issues
4. **Daily Support Analytics Report** – Automated daily summary of support activity

📁 Project Files
- `Workflow 1 - Order Lookup System.json`
- `Workflow 2 - Order Lookup System.json`
- `Workflow 3 - Complaint and Ticket Management.json`
- `Workflow 4 - Admin Notification System.json`
- `Workflow 5 - Daily Support Analytics Report.json`

🚀 Setup
1. Import the JSON files into your n8n instance
2. Connect your Telegram Bot, Gemini AI, and Google Sheets credentials
3. Activate the workflows
